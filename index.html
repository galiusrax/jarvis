Settings

Get a free key at aistudio.google.com/apikey. The key is stored only in this browser and sent only to Google. It is never uploaded to GitHub.

This site uses your private proxy, so no API key is needed here.

Memory

    Stored only in this browser. Tell Jarvis things like "my name is…", "I live in…", "I like…" or "remember that I prefer short answers". It won't store passwords, health, money or other sensitive details. Ask "what do you know about me?" or say "forget…" any time.

    Online brain (GitHub Models)

    Makes Jarvis much smarter: real analysis, open questions and photo interpretation. It is hosted by GitHub (free tier, with limits). Create a fine-grained personal access token with the Models (read) permission and paste it here. It stays only in this browser: never put it in your repository.

    Local AI

    Always on. Jarvis runs a small language model inside your browser: no account, no key, no cloud. It downloads once, then works offline. Until it is ready, the built-in brain answers instantly.
